Sem leitura de temperatura

O Windows não entrega a temperatura da CPU para programas comuns: ela fica em registradores do processador que só o modo kernel lê. O Bifrost resolve isso sozinho, com um driver open-source e assinado. É uma instalação silenciosa, uma janela do Windows pedindo permissão, e nenhum outro programa precisa ficar aberto.

Jogo atual

Mostra na tela o jogo que você está jogando, com capa e tempo jogado.

Lendo direto do app da Steam

Sem API key e sem mexer na privacidade: o Bifrost lê o jogo aberto, o tempo jogado e a capa da Steam instalada neste PC.

Use a Web API se a Steam deste PC não for encontrada ou se você joga em outro computador. Precisa de uma chave pessoal.

Não aparece o jogo?

Pela Web API, a Steam só informa o jogo atual se, em Privacidade, os Detalhes do jogo estiverem como Público.

Partidas ao vivo

Acompanha CS2/CS:GO e Dota 2 (via Game State Integration da Valve) e League of Legends (via a API local da Riot) enquanto uma partida estiver rolando. Sem partida ao vivo, a tela do jogo mostra as estatísticas da conta e o FPS em tempo real (via RivaTuner, se estiver instalado).

No Dota 2 também é preciso adicionar -gamestateintegration nas opções de inicialização do jogo (Steam → Biblioteca → botao direito no Dota 2 → Propriedades → Opções de inicialização), senão o jogo nem lê o arquivo de configuração. O CS2 não precisa disso.

Falta reiniciar o jogo

CS2 e Dota 2 só leem a configuração do acompanhamento ao vivo quando abrem. Como o jogo já estava aberto, feche e abra de novo para os dados ao vivo aparecerem na tela.
