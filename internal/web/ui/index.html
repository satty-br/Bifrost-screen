Jogo atual

Mostra na tela o jogo que você está jogando, com capa e tempo jogado.

Lendo direto do app da Steam

Sem API key e sem mexer na privacidade: o Bifrost lê o jogo aberto, o tempo jogado e a capa da Steam instalada neste PC.

Use a Web API se a Steam deste PC não for encontrada ou se você joga em outro computador. Precisa de uma chave pessoal.

Não aparece o jogo?

Pela Web API, a Steam só informa o jogo atual se, em Privacidade, os Detalhes do jogo estiverem como Público.
